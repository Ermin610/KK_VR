# v0.4.0 相对 v0.3.0 的改动

> 状态：v0.4.0 发布差异记录。
>
> 对比基线：Git 标签 `v0.3.0`。核心插件为 `0.4.0`，配套 CameraSync 为独立安装的 `0.2.3`。

这次更新不只是调整界面，重点是把角色换装、VMD、Timeline、ReShade 和普通工作室启动整理成更完整、稳定的 VR 制作流程。v0.3.0 已有的腕表菜单、三语界面、场景与角色卡读取、基础 MMD 控制、手动高跟鞋参数等功能不再重复列出。

## 多了什么

### 角色与换装

- 新增角色自带服装预设切换，可直接选择校服、运动服、泳装、社团服、便服、睡衣及扩展服装。
- 新增带原生卡面预览的服装卡浏览与换装流程。
- 服装卡现在提供三种常用方式：
  - **只换衣服**：保留角色当前全部饰品；
  - **追加饰品**：把服装卡饰品放入空槽，不覆盖现有头发和头饰；
  - **自选饰品**：进入三级菜单，按需选择本次要追加的饰品。
- 新增“管理追加饰品”，可单独移除或一次清理由本插件追加的饰品。
- 新增“撤销上次换装”；换装前会建立快照，失败时自动回滚。
- 新增绑定型服装卡兼容模式。检测到 Coordinate Load Option、MaterialEditor 等槽位绑定数据时，会先显示风险提示并二次确认，再按原槽位迁移相应数据。
- 角色替换新增“保留当前服装”选项：使用新角色的脸、身体和头发，同时保留当前角色的衣服、鞋袜、服装材质、穿脱状态及由本插件追踪的服装配饰。
- 新增高跟鞋缓存自动识别：有当前角色缓存时自动切到手动模式并应用；没有缓存时恢复自动模式，避免沿用上一名角色的数据。
- VR 换装页新增按服装部位调整透明度：保留 0/25/50/75/100 快捷预设，支持 ±5% 调整和 ±1% 微调；空服装槽会置灰并禁止选择。

### MMD

- 新 VMD 成功载入后默认停止在第一帧，不再继承上一段动作的帧数和播放状态。
- MMD 菜单新增“回到首帧”。
- 新增 MMD 展示模式，可在播放时隐藏手柄、原生控制器、手环、射线和交互界面。
- 展示模式下统一使用**左摇杆按下**播放或暂停；右摇杆上下可连续调整 MMD Fixed FOV。
- 新增 MMD 百分比换装联动，默认全局预设为：
  - 10%：上衣半脱；
  - 20%：下装半脱；
  - 30%：胸罩和内裤半脱；
  - 40%：上衣和下装全脱，裤袜保持穿着，胸罩和内裤保持半脱。
- 全部 VMD 可直接使用全局换装预设，也可以为单个 VMD 创建独立事件表，调整百分比、服装部位和状态。
- 单个 VMD 的自定义配置按内容指纹识别，复制或改名后仍可继续匹配；也可一键删除覆盖并恢复全局预设。
- 时间轴向后跳转、循环重开、回到首帧、更换 VMD 或关闭联动时，会从播放前造型重新计算服装状态，避免重复触发造成状态循环。

### Timeline

- Timeline 从 MMD 二级菜单独立为一级入口，拥有单独的播放与镜头构图页面。
- 新增“跟随 Timeline 摄像机”和“只播放动画”两种模式。
- Timeline 播放与暂停改由右摇杆按下控制，并进入独立的 Timeline 控制空间；MMD 继续由左摇杆控制，两者不再绑在一起。
- 右摇杆上下可连续调整前后构图；按住右手 Grip 后，上下改为线性调整垂直偏移，左右则线性调整水平旋转。
- Timeline 页面可保存、读取或复位当前 FOV、垂直偏移和水平旋转参数。
- Timeline 镜头播放时会暂时锁定位移、世界抓取、角色与 IK 抓取、双手缩放和快捷镜头操作；按下右摇杆暂停后恢复手动控制。

### ReShade、界面与操作

- 新增原生 ReShade 控制桥，可在 VR 设置中真正开关 ReShade，并切换当前预设。
- ReShade 列表会在打开时动态扫描 `reshade-shaders` 根目录中的有效 `.ini`，不再限制为两个固定选项。
- ReShade 开关和当前预设会自动保存，下一次启动继续沿用；普通模式下也可通过配置或快捷键测试。
- 新增手柄快捷键布局选择：双手分配、集中左手或集中右手。
- 新增工作室原生 GUI 的距离、大小调节和一键召回。
- 腕表在本次运行中会记住最后一个稳定页面，关闭后重新打开无需从主菜单重新查找。
- 角色卡和服装卡列表改为文件夹优先、单张卡靠后；同类项目按最后修改时间倒序显示。
- 新增设置即时保存，重启后继续沿用已选择的默认值。

### 启动方式

- 新增明确区分的 VR 与普通工作室启动器。
- VR 启动必须显式使用 `--studiovr -vrmode OpenVR`，仅仅在后台运行 SteamVR 不会再自动进入 VR。
- 普通工作室使用 `--novr -vrmode None`，从 Unity 启动阶段阻止 OpenVR 载入。

## 修了什么

### 角色、服装与高跟鞋

- 修复完整换装覆盖头发饰品、导致角色变光头的问题；普通完整换装现在改为向空槽追加饰品。
- 修复连续读取同一服装卡后头饰不断重复叠加、且无法清理的问题。
- 修复部分带槽位绑定数据的服装卡无法完整替换，或失败后留下残缺角色状态的问题。
- 修复换装中途失败后衣服、饰品或扩展数据只改了一半的问题，增加事务快照、回滚和撤销。
- 修复高跟鞋手动参数串到其他角色、无缓存角色继续沿用上一角色手动模式的问题。
- 修复 MotionController 尚未创建时高跟鞋缓存无法应用的问题；现在会在角色、换装、换鞋或 VMD 控制器稳定后重新检查。

### VMD 与角色替换

- 修复替换正在播放 VMD 的角色时，新角色直接继承旧控制器并发生骨骼变形的问题。现在会先解绑旧 VMD，替换并等待新骨架稳定，再重新绑定同一份动作。
- 修复重复载入新 VMD 时旧动作、变形和播放进度没有清理的问题。
- 修复 VMD 载入失败后原动作、镜头或音频丢失的问题；失败时会尽量恢复载入前状态。
- 修复场景或角色变化后 MMDD 仍持有已销毁角色控制器，导致后续 VMD 读取失败的问题。
- 修复替换动作后仍从旧时间点继续播放的问题；成功载入后统一停在首帧。

### Timeline、镜头与场景稳定性

- 修复 Timeline 播放期间摇杆移动、GripMove 和 CameraSync 同时写入 VR 原点，造成镜头乱飞、漂移或重复位移的问题。
- 重做 Timeline FOV 到 VR 构图的传递链路；现在由 CameraSync 使用有边界的前后构图补偿，不再只是界面数值发生变化。
- 修复动态调整构图时多个镜头写入器叠加，导致视点中心漂移的问题。
- 增加异常 FOV、NaN 和极端关键帧过滤，避免视点被突然甩出场景。
- 修复 Timeline 运镜期间仍可误触移动、抓取、缩放、普通转向或右手撤销的问题；右摇杆点击在 Timeline 控制空间中只负责播放与暂停。
- 修复一次场景载入被重复判定完成，造成控制器重复恢复和摄像机重复对齐的问题。
- 修复部分场景载入、控制器重连或展示模式异常退出后单手或双手永久消失的问题；左右手现在分别检查和重新绑定。
- 修复暂停、自然结束、换场景或异常时展示隐藏状态没有清理，导致手柄、手环或交互界面无法恢复的问题。

### ReShade、浏览器与普通模式

- 修复 ReShade 预设只能看到两个静态选项的问题。
- 修复腕表中的“关闭 ReShade”只改界面状态、实际效果仍在运行的问题。
- 修复 ReShade 选择不能持久保存、重新打开列表不能反映根目录变化的问题。
- 修复文件浏览、翻页、返回和更换目录时可能发生索引越界的问题。
- 修复旧整合包只加 `--novr` 时，Unity 仍会提前载入 `openvr_api.dll` 的问题。普通启动器现在同时使用 `--novr -vrmode None`；本机验证时 `openvr_api.dll` 与 `vrclient_x64.dll` 均未进入普通工作室进程。
- 修复仅因 SteamVR 在后台运行就触发 VR 插件的问题，普通模式不再安装 VRLoader、CameraSync 驱动或 VR 专用补丁。

## 说明

- 当前内容描述 v0.4.0 相对 v0.3.0 的主要变化；具体安装内容以 v0.4.0 发布包为准。
- Timeline 的 FOV 功能是让 VR 中的构图接近桌面摄像机画面，通过前后距离补偿实现；它不会直接改变头显自身的光学视场角。不同场景仍需要进行最终头显对比验收。
- ReShade 只扫描 `reshade-shaders` 根目录中的有效预设，不递归读取备份、实验或其他子目录。
- MMDD、VNGE、Coordinate Load Option 和 MaterialEditor 均为独立第三方插件；本项目新增的是 VR 控制、流程编排和兼容桥，不包含或重新实现这些插件。
- 腕表页面记忆仅在本次运行中生效；游戏冷启动后仍从主菜单开始。
